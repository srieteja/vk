<task type="auto">
  <name>Task 2: Create centralized validators package</name>
  <files>internal/validators/validators.go</files>
  <action>
Create `internal/validators/validators.go` with validation functions from research Pattern 1 and Pattern 5:

1. **EscapeLikeWildcards** function:
   - Escapes SQL LIKE wildcard characters (\, %, _)
   - Escape backslash FIRST to prevent double-escaping issues
   - Returns sanitized string safe for LIKE queries

2. **Validation structs** with go-playground/validator tags:
   - LoginRequest: email (required, email, max=255), password (required, min=8, max=72)
   - RegisterRequest: email (required, email, max=255), password (required, min=8, max=72), name (required, min=2, max=100)
   - ProfileImageRequest: image_url (required, url, max=2048)
   - LocationFilter: location (omitempty, max=100)

3. **ValidateLoginRequest** function:
   - Uses validator.New() with RequiredStructEnabled
   - Returns validation error with context

4. **ValidateRegisterRequest** function:
   - Validates struct via validator
   - Additional password length check (min 8 chars)
   - Returns descriptive errors

5. **ValidateImageURL** function:
   - Validates URL format via validator
   - Parses URL and checks scheme is HTTPS only
   - Calls isPrivateIP helper to prevent SSRF
   - Returns error if private IP detected

6. **isPrivateIP** helper:
   - Parses hostname as IP
   - Uses net.ParseIP and checks IsLoopback(), IsPrivate(), IsLinkLocalUnicast()
   - Returns false for non-IP hostnames (domains assumed safe)

7. **SanitizeHTML** function:
   - Uses bluemonday.UGCPolicy() for safe HTML formatting
   - Allows class attribute on span/div/p with alphanumeric pattern
   - Returns sanitized HTML

8. **SanitizePlainText** function:
   - Uses bluemonday.StrictPolicy() to strip ALL HTML
   - Returns plain text only

Implementation reference: Research PLAN.md Pattern 5 (lines 474-634).

Do NOT integrate with handlers yet - this task only creates the validators package.
