  <files>internal/middleware/rate_limit.go</files>
  <action>
Create `internal/middleware/rate_limit.go` implementing research Pattern 2 (lines 162-255):

1. **InitializeRateLimiting** function:
   - Takes redisClient *redis.Client parameter
   - Returns map[string]gin.HandlerFunc with rate limiters for different endpoint categories

   **Auth rate limiter (5 req/min per IP):**
   - Rate: `limiter.NewRateFromFormatted("5-M")` (5 per minute)
   - Store: Redis with prefix "ratelimit:auth:"
   - Limiter: Use limitergin.NewMiddleware with WithTrustForwardHeader(true) for proxy support

   **OAuth rate limiter (10 req/min per IP):**
   - Rate: `limiter.NewRateFromFormatted("10-M")`
   - Store: Redis with prefix "ratelimit:oauth:"
   - Limiter: Use limitergin.NewMiddleware with WithTrustForwardHeader(true)

   **Payment rate limiter (10 req/min per user):**
   - Rate: `limiter.NewRateFromFormatted("10-M")`
   - Store: Redis with prefix "ratelimit:payment:"
   - Limiter: Custom PaymentRateLimiter function (see below)

2. **PaymentRateLimiter** function:
   - Takes limiter *limiter.Limiter parameter
   - Returns gin.HandlerFunc
   - Extracts user_id from context (set by AuthMiddleware)
   - If user_id missing, return 401 unauthorized
   - Calls limiter.Get(ctx, userID) to check rate limit
   - If limit reached (ctx.Reached), return 429 with "rate limit exceeded"
   - Otherwise call c.Next()

Implementation reference: Research Pattern 2, lines 173-231.

CRITICAL: Use WithTrustForwardHeader(true) for IP-based rate limiting to work correctly behind proxies/load balancers.

Import paths:
```go
import (
    "github.com/gin-gonic/gin"
    "github.com/redis/go-redis/v9"
    "github.com/ulule/limiter/v3"
    limitergin "github.com/ulule/limiter/v3/drivers/middleware/gin"
    limiterredis "github.com/ulule/limiter/v3/drivers/store/redis"
)
```
